# Scheiber V8 control panel

The dedicated control-panel reverse-engineering section is:

**[`docs/control-panel-v8/README.md`](docs/control-panel-v8/README.md)**

It contains the panel photo, immutable raw captures, complete key/output map, CAN frame format, steaming/navigation interlock, bilge modes, fresh-water-pump running feedback, reproducible decoder/control tooling, regression tests, and a future-agent handoff.

> **Physical prerequisite:** the control panel must first be connected with its normal Scheiber X1/X2 V8 CAN cable to the rest of the vessel network. A bench-isolated panel is not equivalent to the installed distributed control system.

Start with the section README, then read [`docs/control-panel-v8/HANDOFF.md`](docs/control-panel-v8/HANDOFF.md).
